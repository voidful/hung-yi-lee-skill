## 第一部分：這個 skill 到底是怎麼想出來的？ (Motivation) 🤔

假設你今天想要打造一個「像某個老師上課」的 AI。
第一個出現在你腦海裡的想法是什麼？

你可能會想說：*「那很簡單嘛！就把他的影片字幕全部抓下來，用向量搜尋（RAG）餵給 LLM，不就結束了嗎？」*
對，這就是最直覺的想法，我們也確實用這個方法做出了第一版。

**但是，這個做法有一個你想不到的極限。**

為什麼？因為逐字稿這東西，有非常嚴重的**「倖存者偏差」**！
逐字稿只記錄了老師在鏡頭前講出來的台詞。但是：
* 老師在後台是怎麼備課的？
* 哪些教學方法他試過，發現學生聽不懂，最後又丟掉的？
* 他為什麼刻意不講某些複雜的數學公式？

這些鏡頭背後的「負空間」，逐字稿裡通通都沒有！你如果只用 RAG，做出來的 AI 就只是在 cosplay、在學皮毛而已，根本沒有學到靈魂。

那怎麼辦呢？我們做了三個很關鍵的步驟：

```
                    【 我們的「靈魂逆向工程」三步驟 】

    Step 1: 頻率探勘 ───> Step 2: 產生訪談腳本 ───> Step 3: 真的去對答案
   (用 Fable 5 挖語癖)      (自動產生 10 道對比題)     (跟老師本人訪談，校準一切)
```

1. **第一步 — 用 Fable 5 挖出真正的語感 DNA**
   我們用 `claude-fable-5` 對 27 份完整逐字稿做頻率探勘，算出真正的招牌語癖：`比如說` 出現了 609 次、`假設` 518 次、`而已` 160 次、`就結束了` 36 次，還有那句經典的「硬 train 一發」！這些不是我們憑感覺加的，是實打實數出來的喔。
2. **第二步 — 自動生成訪談腳本**
   我們用 Fable 5 跑了一個多 agent 系統，自動生成一份非常硬核的「風格岔路訪談腳本」（放在 [`references/interview-protocol.md`](references/interview-protocol.md)）。
3. **第三步 — 真的去找老師對答案！**
   這不是我們自己自嗨喔，我們真的去訪談了老師本人！本人的回答直接寫進 `SKILL.md` 的最頂層（First-Person Calibration 區塊）。**本人的回答凌駕一切推論！**

訪談完我們才發現很多驚人的事實（你沒有看錯，我們以前都猜錯了）：
* ❌ 我們原本以為開場講「熱騰騰的文件」很生動。 ───> 🔴 老師說：他才不會講「熱騰騰」這詞，聽起來很出戲。
* ❌ 嚇人的事拿日常生活比喻（像是國中清瀏覽器記錄）。 ───> 🔴 老師說：這太普通、沒有梗，他會用「更莫名其妙的動漫比喻」（像是《芙莉蓮》的魔族）。
* ❌ 只要給 AI 規則就好了。 ───> 🔴 老師親口給了三條規則：**內容要有脈絡、一定要有梗、教方法要引導思考「這方法是怎麼被想出來的」**。

一言以蔽之：**這個 skill 不是隨便 cosplay，是逆向工程之後，再回去跟本人對答案的成果！**

## 第二部分：它裡面到底裝了什麼神奇的東西？ (Inside the Box) 📦

好，我們現在走完第一部分了，接下來進入第二部分。
你可能會想說：*「那這個 skill 裡面到底裝了什麼？不就是一個普通的 markdown 檔案而已嗎？」*

其實不是喔，它背後有一個非常龐大、由課程語料硬 train 出來的**知識圖譜（Knowledge Graph）**！

### 📊 知識圖譜的驚人數據 (Graph Stats)

| 指標 | 數值 | 白話文意思 |
|------|------|------------|
| **節點 (Nodes)** | `916` | 裡面收錄了 916 個不同的機器學習概念與影片 |
| **邊 (Edges)** | `3,664` | 這些概念之間，有 3664 條連線關係 |
| **社群 (Communities)** | `10` | 系統自動把相關的概念分成了 10 個朋友圈（社群） |
| **EXTRACTED 邊** | `1,621` | 從字幕裡實打實抓出來的直接關係 |
| **INFERRED 邊** | `2,043` | 根據語意和課程脈絡推論出來的關係 |

### 🌟 整個課程的「黃金交叉路口」 (God Nodes)

在 916 個概念裡，有一些節點連線度極高，代表幾乎所有知識都要經過它：
1. **Ml Fundamentals** (topic) ── 連結度 385（機器學習的基本原理，一切的起點）
2. **語言模型** (concept) ── 連結度 251（文字接龍的核心）
3. **Standalone Talks** (series) ── 連結度 148（各式各樣的神奇專題演講）
4. **Llama** (concept) ── 連結度 101（Meta 開源神作系列）
5. **解剖** (concept) ── 連結度 100（把大模型拆開來看裡面的技術）

### 🗺️ 10 個不同的概念朋友圈 (Communities)

我們用圖譜拓撲算法，把這 916 個節點自動分類，你會發現有這幾個主要圈子：
* **ML Fundamentals (396 節點)** ── Regression、Classification 這些基本功都在這。
* **Diffusion And Generation (116 節點)** ── 影像生成、擴散模型、Flow Matching。
* **Speech And Audio (81 節點)** ── 語音辨識、TTS、語音語言模型。
* **AI Agent (72 節點)** ── Context Engineering、Agent 的運作機制。
* **Model Editing (33 節點)** ── 神奇的 Model Merging、Task Vector 技術。

## 第三部分：怎麼把它裝進去，然後硬 train 一發？ (Implementation) 💻

好，我們現在走完前兩步了，接下來進入實作！
怎麼把這個 skill 裝到你的電腦裡呢？其實很簡單，就是三個指令而已。

### 1. 下載並安裝依賴

```bash
# 1. 複製這個專案
git clone https://github.com/voidful/hung-yi-lee-skill.git
cd hung-yi-lee-skill

# 2. 安裝必要的套件 (youtube-transcript-api, networkx, python-louvain)
pip install -r requirements.txt
```

### 2. 放到你的 AI 助理目錄
你只需要把這個目錄放到你的 AI coding assistant (像是 Claude Code、Cursor、Hermes 等) 可以讀到的地方，讓 it 讀取 `SKILL.md`，它就會自動載入這整套教學思維！

這時候你就可以開始問它：
```
> 用李宏毅老師的風格幫我解釋 Transformer。
> 老師會怎麼看這份 AI 安全報告？
> 什麼是 self-supervised learning？像老師上課那樣講。
```

### 3. 本地端工具指令 (CLI Tools)

這個專案附帶了很強大的 Python 工具，你可以在終端機直接跑：

```bash
# 🔍 搜尋影片逐字稿
python3 scripts/hungyi_kb.py search "attention" --limit 8

# 🕸️ 查詢知識圖譜
python3 scripts/hungyi_kb.py graph query "什麼是 transformer"

# 📊 重新產出圖譜分析報告
python3 scripts/hungyi_kb.py graph report

# 🩺 檢查專案健康狀況 (Lint)
python3 scripts/hungyi_kb.py lint
```
